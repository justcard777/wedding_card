# Royal Rajasthani Wedding Invitation

A responsive wedding invitation built with HTML5, CSS3 and vanilla JavaScript.

## Run locally
Open `index.html` in a modern browser. For best results, use a small local web server (for example, VS Code Live Server).

## Replace the two couple photographs
Keep these exact filenames and replace the placeholder files with your own photographs:
- `assets/photos/divya-pawan.jpg` — Divya and Pawan
- `assets/photos/bharti-aman.jpg` — Bharti and Aman

Recommended: compressed JPG or WebP images, around 1200px on the long edge. If using WebP, update the matching `src` in `index.html`.

## Add background music
Place a wedding instrumental or shehnai track that you have permission to use at:
`assets/audio/wedding-music.mp3`

The music button starts playback only after the visitor clicks it. No autoplay is used.
